# 冊子風リデザインの方向性メモ

`booklet.html` / `booklet.css` は、サイト全体を「演劇祭のプログラム冊子」風に作り替えるための、2025年1ページ分のモック。確認は `python -m http.server` などで配信して開く（file:// 直開きでは CSS が当たらない環境がある）。

## 決めたこと

- **コンセプト: 冊子**。1年＝冊子の1ページ。年表案は1年が1行に圧縮され大賞以外が脚注になるため不採用。
- **受賞者は全員同じ重さで載せる**。大賞もその他の賞も文字サイズ・ウェイト・余白を同一にし、大賞は賞名のインクを朱色にするだけ。アイコンや枠などの装飾で差を付けない。
- **受賞者名を主役に**。賞名は小さく左列、右列に受賞者名（大）と作品名（小）。
- **書体**: 日本語・本文は Shippori Mincho、年号の大数字と欧文飾りは Cormorant Garamond 300。
- **配色**: 机（外側）／紙／インク／薄インク／罫／朱の6変数。ライト・ダーク両対応。
- **背表紙ナビ**: 画面左端に 2025→2006 を縦書きで固定表示。現在ページは朱の縦線。800px 未満では紙の上の横スクロール行になる。
- **紙の表現**: 中央の紙にわずかな影と、内側16pxの罫枠。ページ番号は「— 20 —」（第N回＝ページ番号）。
- **動き**: 受賞行の読み込み時フェードインのみ（CSS、reduced-motion で無効）。JS なし。
- **写真は使わない**。劇団・公演写真の転載は権利面で避け、文字組みで勝負する。

## 次の作業

1. `build.py` のテンプレートを冊子構造（背表紙ナビ＋年ごとの `.page`）に置き換える。全年を1ページにスクロールで並べるか、年ごとに別ファイルを出力するかは未決定。
2. `style.css` を `booklet.css` ベースに書き直す。
3. 「該当なし」行・作品名なし行（`work` が空）の扱いを build.py 側で `booklet.html` と同じマークアップに揃える。
4. 背表紙は20年を縦に等間隔で並べているため、画面高さ約500px以下で年号が重なる可能性がある。実装時に要対処。
5. ヘッダーの舞台イラスト・統計タイル（現行 index.html）は冊子コンセプトと合わないため、扉ページ（表紙）として再設計するか廃止するかを決める。
